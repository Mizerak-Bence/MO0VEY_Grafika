Assets used by the semester project.

- models/: only the OBJ files actually referenced by the program should stay committed
- textures/: only the PNG/JPEG files actually referenced by the program should stay committed

Current runtime asset set:
- `models/cube.obj`
- `models/ISAAC2.obj`
- `textures/checker.png`
- `textures/4_ons_black_bg_1920x1080.png`

Do not commit:
- import/source assets,
- generator scripts,
- unused model or texture variants,
- generated image output that is not referenced by the program.

If you decide to use a larger asset pack:
1) Zip the whole assets/ folder.
2) Upload it to a cloud storage (OneDrive/Dropbox/etc.).
3) Put the download link into Beadando/README.md.
